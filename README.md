# Projeto 1 - Programação Web Fullstack

## 📌 Descrição do Projeto
O Projeto 1 da disciplina **Programação Web Fullstack** consiste no desenvolvimento da camada **Frontend** de uma aplicação web moderna. A aplicação utiliza **React.js** e requisições assíncronas via **AJAX**, sendo desenvolvida no conceito de **SPA (Single Page Application)**. Todas as funcionalidades e navegações são manipuladas dinamicamente em uma única página HTML, garantindo uma interface fluida sem a necessidade de recarregar a página ou redirecionar o usuário.

## 🛠️ Tecnologias Utilizadas
- **React.js**: Biblioteca principal para a criação da interface reativa.
- **AJAX / Axios / Fetch API**: Para comunicação assíncrona com serviços/APIs externas.
- **JavaScript (ES6+)**: Linguagem base para a lógica do Frontend.
- **HTML5 & CSS3**: Estruturação e estilização das rotas/componentes dinâmicos.
